# Registrai Data API v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve Arc index and per-app hourly data as a public, documented, versioned API at
`https://builder.registrai.cc/api/v1`. Genara is the first consumer.

**Architecture:**
- **Ingest:** every index push (`POST /api/index[/aii|/aei]`, which already exists) also writes that hour's rows to
  a new D1 database `registrai-data` (`DATA_DB`). The rows are index closes from `candles` and member rows from
  `live.P` plus that hour's activity events.
- **Read handlers:** they read D1 (history) and the KV index files (current state), and answer with CORS `*`, an
  etag and the edge cache.
- **Verified projects:** read live from the mainnet BuilderRegistry with the same proof validation the gallery uses,
  cached in KV for 5 minutes.
- **Backfill:** a one-off script loads the history from the server's hourly archives.

**Tech Stack:**
- Cloudflare Pages Functions (TypeScript), D1, KV;
- viem, for the registry reads;
- vitest, with the repo's `MemoryD1`, `MemoryKV` and `MemoryCache` doubles;
- Next.js static export, for the docs page.

**Spec:** `docs/superpowers/specs/2026-10-14-data-api-v1-design.md` (approved 2026-10-14). Contract fixtures are in
`docs/superpowers/specs/data-api-v1-fixtures/`.

## Global Constraints

- Every response carries `"version": 1`. History and member responses also carry `data_until` (ISO hour close).
  `/verified` carries `updated` instead.
- Headers on every v1 response:
  - `access-control-allow-origin: *`;
  - `content-type: application/json; charset=utf-8`;
  - `x-content-type-options: nosniff`;
  - `etag: "<sha256 hex of the body>"`.
  A 200 is `cache-control: public, max-age=60`, or `max-age=300` on `/verified`.
- Request handling:
  - a request with `if-none-match` equal to the etag gets a 304 with no body;
  - GET only, anything else returns 405 `{error}`.
- Errors are `{ "error": "<plain sentence>" }`. A missing upstream (DB binding absent, no KV file, no rows at all)
  returns 503, never an empty 200, and a response is never partial.
- Member `id` is the index `source`, unchanged; in a path it is URL-encoded.
- Query parameters:
  - `from`, `to`, `since` and `hour` are ISO hour closes only (`YYYY-MM-DDTHH:00:00Z`);
  - `from` and `to` are inclusive;
  - with neither, the window ends at `data_until` and is the cap long; with one, it extends from it to the cap;
  - the caps are 744 h for index and member history and 168 h for `members/hourly`;
  - over the cap, `from > to`, a non-hour time, or `index` not in `abi|aii|aei` returns 400.
- Hours:
  - `hour = unix_seconds / 3600` of the close;
  - a missed hour has no row, never `null`;
  - `data_until` per index = `MAX(hour)` in `index_hour`; on `/indices` it is the minimum over the three.
- Fields and precision:
  - member `points` is the stock at the close, from `live.P` at full precision;
  - `points_earned` is that hour's activity event `points`;
  - `close` comes from `candles` (3 dp), whose rows are stamped at the hour's START, so the close for hour-close H is
    the candle with `t = H − 1h`;
  - activity events are also stamped at the hour's start: the activity of hour-close H is the event with
    `t = H − 1h`.
- Public data only:
  - no builder addresses or countries in `/verified`;
  - the index method is unchanged.
- Never deploy without passing tests: the full suite may fail only on the known `src/lib/drafts.test.ts`, and lint
  must be clean.
- Deploys:
  - builder site: from the clean worktree `.worktrees/abi-deploy` with `npm run build`, then
    `bash scripts/build-builders-site.sh`, then `bash scripts/deploy-builders-site.sh`;
  - main site (registrai.cc): needs the owner's explicit OK.
- Copy is plain labels, with no slogans (owner's global rules).

```ts
/** Data API v1: the rows one index file contributes (spec 2026-10-14-data-api-v1-design.md, "How the data gets in"). Pure. */
import type { AbiData } from "../../src/lib/builders-index";

export type IndexId = "abi" | "aii" | "aei";
export const INDEX_IDS: IndexId[] = ["abi", "aii", "aei"];
export type IndexHourRow = { index: IndexId; hour: number; close: number };
export type MemberHourRow = { index: IndexId; id: string; hour: number; points: number; points_earned: number; payments: number; wallets: number; new_payers: number; usdc: number };

const HOUR_RE = /^\d{4}-\d{2}-\d{2}T\d{2}:00:00Z$/;
/** unix/3600 of an exact ISO hour (`YYYY-MM-DDTHH:00:00Z`); null for anything else. */
export function hourOf(iso: string): number | null {
  if (!HOUR_RE.test(iso)) return null;
  const t = Date.parse(iso);
  return Number.isFinite(t) ? t / 3600e3 : null;
}
export const isoHour = (h: number) => new Date(h * 3600e3).toISOString().replace(".000Z", "Z");

/** Index closes from candles. A candle is stamped at its hour's start; its close is the close of hour start+1h. */
export function indexHourRows(index: IndexId, d: AbiData, sinceHour = -Infinity): IndexHourRow[] {
  const out: IndexHourRow[] = [];
  for (const c of d.candles ?? []) {
    const start = hourOf(c[0]);
    if (start === null || start + 1 < sinceHour) continue;
    out.push({ index, hour: start + 1, close: c[4] });
  }
  return out;
}

/** Member rows for the file's closed hour: stock from live.P, activity from the events of that hour (stamped at its start). */
export function memberHourRows(index: IndexId, d: AbiData): MemberHourRow[] {
  const hour = hourOf(d.data_until);
  const P = d.live?.P;
  if (hour === null || !P) return [];
  const startIso = isoHour(hour - 1);
  const act = new Map(d.events.filter((e) => e.kind === "activity" && e.t === startIso).map((e) => [e.source, e]));
  return d.projects
    .filter((p) => typeof P[p.source] === "number" && Number.isFinite(P[p.source]))
    .map((p) => {
      const e = act.get(p.source);
      return { index, id: p.source, hour, points: P[p.source], points_earned: e?.points ?? 0, payments: e?.payments ?? 0, wallets: e?.wallets ?? 0, new_payers: e?.new_payers ?? 0, usdc: e?.usdc ?? 0 };
    })
    .sort((a, b) => (a.id < b.id ? -1 : a.id > b.id ? 1 : 0));
}
```

```ts
/** Data API v1 ingest: upserts the rows of one pushed index file into DATA_DB. Never throws (the KV publish must not fail on it). */
import type { AbiData } from "../../src/lib/builders-index";
import type { D1Database } from "./env";
import { indexHourRows, memberHourRows, type IndexHourRow, type IndexId, type MemberHourRow } from "./data-api-rows";

export const DATA_MIGRATIONS = ["0001_data_api.sql"];
/** Closes are re-upserted for this many hours back on every push, so a gap of up to two days heals itself. */
export const INGEST_INDEX_LOOKBACK_H = 48;

export function upsertSql(rows: (IndexHourRow | MemberHourRow)[]): { sql: string; params: unknown[] }[] {
  return rows.map((r) =>
    "id" in r
      ? { sql: "INSERT OR REPLACE INTO member_hour (idx, id, hour, points, points_earned, payments, wallets, new_payers, usdc) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)",
          params: [r.index, r.id, r.hour, r.points, r.points_earned, r.payments, r.wallets, r.new_payers, r.usdc] }
      : { sql: "INSERT OR REPLACE INTO index_hour (idx, hour, close) VALUES (?, ?, ?)", params: [r.index, r.hour, r.close] });
}

export async function ingestIndexFile(db: D1Database | undefined, index: IndexId, d: AbiData): Promise<{ index: number; members: number } | null> {
  if (!db) return null;
  try {
    const until = Date.parse(d.data_until) / 3600e3;
    const closes = indexHourRows(index, d, until - INGEST_INDEX_LOOKBACK_H);
    const members = memberHourRows(index, d);
    const stmts = upsertSql([...closes, ...members]).map((s) => db.prepare(s.sql).bind(...s.params));
    if (stmts.length) await db.batch(stmts);
    return { index: closes.length, members: members.length };
  } catch (err) {
    console.warn("data-api ingest failed", index, err);
    return null;
  }
}
```

```ts
/**
 * Registrai Data API v1 (spec docs/superpowers/specs/2026-10-14-data-api-v1-design.md): public, read-only, versioned.
 * History from DATA_DB (registrai-data), current state from the KV index files. CORS *, sha256 etag (304 on match),
 * edge-cached 60 s with a cache variant built from VALIDATED params only.
 */
import { ABI_INDICES, sha256Hex, type AbiData } from "../../src/lib/builders-index";
import { hourOf, isoHour, INDEX_IDS, type IndexId } from "./data-api-rows";
import type { D1Database, Env } from "./env";
import { edgeCachedGet, type EdgeCacheDeps } from "./http";

export const V1_CACHE_S = 60;
export const INDEX_CAP_H = 744;
export const MEMBERS_HOURLY_CAP_H = 168;
const BASE_DATE = "2026-10-02T00:00:00Z";
const NAMES: Record<IndexId, string> = { abi: "Arc Builders Index", aii: "Arc Integrations Index", aei: "Arc Ecosystem Index" };
const HEADERS = { "content-type": "application/json; charset=utf-8", "x-content-type-options": "nosniff", "access-control-allow-origin": "*" };

export const v1Error = (status: number, error: string) =>
  new Response(JSON.stringify({ error }), { status, headers: { ...HEADERS, "cache-control": "no-store" } });

/** A v1 JSON response: version first, sha256 etag, 304 when if-none-match matches. */
export async function v1Json(req: Request, body: Record<string, unknown>, maxAge = V1_CACHE_S): Promise<Response> {
  const text = JSON.stringify({ version: 1, ...body });
  const etag = `"${await sha256Hex(text)}"`;
  if (req.headers.get("if-none-match") === etag) return new Response(null, { status: 304, headers: { ...HEADERS, etag } });
  return new Response(text, { status: 200, headers: { ...HEADERS, etag, "cache-control": `public, max-age=${maxAge}` } });
}

/** edgeCachedGet, then the 304 check again (a cache hit returns the stored 200 as is). */
export async function cached(req: Request, deps: EdgeCacheDeps, variant: string, produce: () => Promise<Response>, ttl = V1_CACHE_S): Promise<Response> {
  if (req.method.toUpperCase() !== "GET") return v1Error(405, "Only GET is supported.");
  const res = await edgeCachedGet(req, deps, produce, ttl, variant);
  const etag = res.headers.get("etag");
  if (res.status === 200 && etag && req.headers.get("if-none-match") === etag) return new Response(null, { status: 304, headers: { ...HEADERS, etag } });
  return res;
}

export const parseIndex = (v: string | null): IndexId | null => (INDEX_IDS as string[]).includes(v ?? "") ? (v as IndexId) : null;

/** from/to (ISO hour closes, inclusive). Neither: the cap-long window ending at data_until; one: up to the cap from it. */
export function parseWindow(url: URL, untilHour: number, cap: number): { from: number; to: number } | { error: string } {
  const f = url.searchParams.get("from"), t = url.searchParams.get("to");
  const from = f === null ? null : hourOf(f), to = t === null ? null : hourOf(t);
  if ((f !== null && from === null) || (t !== null && to === null)) return { error: "from and to must be ISO hour closes, like 2026-10-14T19:00:00Z." };
  let a: number, b: number;
  if (from === null && to === null) { b = untilHour; a = b - cap + 1; }
  else if (from !== null && to === null) { a = from; b = Math.min(from + cap - 1, untilHour); }
  else if (from === null) { b = to!; a = b - cap + 1; }
  else { a = from; b = to!; }
  if (a > b) return { error: "from must not be after to." };
  if (b - a + 1 > cap) return { error: `A request covers at most ${cap} hours.` };
  return { from: a, to: b };
}

export async function dataUntil(db: D1Database, index: IndexId): Promise<number | null> {
  const r = await db.prepare("SELECT MAX(hour) AS h FROM index_hour WHERE idx = ?").bind(index).first<{ h: number | null }>();
  return r?.h ?? null;
}

async function indexFile(env: Env, id: IndexId): Promise<AbiData | null> {
  try { return JSON.parse((await env.INVITES.get(ABI_INDICES[id].key)) ?? "null") as AbiData | null; } catch { return null; }
}
const lastClose = (d: AbiData) => d.candles?.length ? d.candles[d.candles.length - 1][4] : null;

export function handleIndices(req: Request, env: Env, deps: EdgeCacheDeps = {}): Promise<Response> {
  return cached(req, deps, "indices", async () => {
    const files = await Promise.all(INDEX_IDS.map((id) => indexFile(env, id)));
    if (files.some((f) => !f || lastClose(f) === null || hourOf(f.data_until) === null)) return v1Error(503, "The index data is not available right now. Retry later.");
    const fs = files as AbiData[];
    const until = Math.min(...fs.map((f) => hourOf(f.data_until)!));
    const p = fs[0].params as { half_life_days: number; decay_per_hour_pct: number };
    return v1Json(req, {
      data_until: isoHour(until),
      indices: Object.fromEntries(INDEX_IDS.map((id, i) => [id, { name: NAMES[id], close: lastClose(fs[i]), close_24h_ago: fs[i].index_24h_ago, base: 1000, base_date: BASE_DATE, members: fs[i].projects.length }])),
      params: { half_life_days: p.half_life_days, decay_per_hour_pct: p.decay_per_hour_pct },
    });
  });
}

export function handleIndexHourly(req: Request, env: Env, index: IndexId, deps: EdgeCacheDeps = {}): Promise<Response> {
  const url = new URL(req.url);
  return (async () => {
    const db = env.DATA_DB;
    if (!db) return v1Error(503, "History is not available right now. Retry later.");
    const until = await dataUntil(db, index);
    if (until === null) return v1Error(503, "History is not available right now. Retry later.");
    const w = parseWindow(url, until, INDEX_CAP_H);
    if ("error" in w) return v1Error(400, w.error);
    return cached(req, deps, `ih:${index}:${w.from}:${w.to}:${until}`, async () => {
      const rows = (await db.prepare("SELECT hour, close FROM index_hour WHERE idx = ? AND hour BETWEEN ? AND ? ORDER BY hour").bind(index, w.from, w.to).all<{ hour: number; close: number }>()).results;
      return v1Json(req, { index, data_until: isoHour(until), rows: rows.map((r) => ({ hour_close: isoHour(r.hour), hour: r.hour, close: r.close })) });
    });
  })();
}
```

```ts
/** Data API v1 /verified: projects whose proof validates against the mainnet BuilderRegistry (same rules as the gallery). KV-cached 5 min. */
import { createPublicClient, http } from "viem";
import { BUILDERS } from "../../src/lib/builders-network";
import { proofConfigFromEnv } from "../../src/lib/verified-builders";
import { makeFetchJson, readBuilderRecords, type BuilderRecord, type RegistryReader } from "../../src/lib/verified-builders-chain";
import { isoHour } from "./data-api-rows";
import { cached, v1Error, v1Json } from "./data-api";
import type { Env } from "./env";
import type { EdgeCacheDeps } from "./http";

export const VERIFIED_KEY = "data:verified";
export const VERIFIED_TTL_S = 300;
export type VerifiedEntry = { id: string; method: "registry"; since: string };
type Read = () => Promise<BuilderRecord[]>;

export function verifiedFromRecords(records: BuilderRecord[]): VerifiedEntry[] {
  const best = new Map<string, number>();
  for (const b of records) {
    if (!b.active) continue;
    for (const p of b.projects) {
      if (p.status !== "verified" || !p.canonical || !p.active) continue;
      const h = Math.floor(p.addedAt / 3600);
      best.set(p.source, Math.min(best.get(p.source) ?? Infinity, h));
    }
  }
  return [...best].sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0)).map(([id, h]) => ({ id, method: "registry" as const, since: isoHour(h) }));
}

const chainRead = (env: Env): Read => async () => {
  const client = createPublicClient({ chain: BUILDERS.chain.viemChain, transport: http(BUILDERS.rpc, { retryCount: 2, retryDelay: 400 }) });
  return readBuilderRecords(client as unknown as RegistryReader, {
    builderRegistry: BUILDERS.contracts.BuilderRegistry!, caretakerRegistry: BUILDERS.contracts.CaretakerRegistry, operator: BUILDERS.operator,
    chainId: BUILDERS.chainId, proofConfig: proofConfigFromEnv(env as unknown as Record<string, string | undefined>), fetchJson: makeFetchJson({ timeoutMs: 8_000 }),
  });
};

export async function loadVerified(env: Env, _deps: EdgeCacheDeps, read: Read = chainRead(env)): Promise<{ updated: string; verified: VerifiedEntry[] } | null> {
  let stale: { updated: string; verified: VerifiedEntry[] } | null = null;
  try { stale = JSON.parse((await env.INVITES.get(VERIFIED_KEY)) ?? "null"); } catch { stale = null; }
  if (stale && Date.now() - Date.parse(stale.updated) < VERIFIED_TTL_S * 1000) return stale;
  try {
    const fresh = { updated: new Date().toISOString().replace(/\.\d{3}Z$/, "Z"), verified: verifiedFromRecords(await read()) };
    await env.INVITES.put(VERIFIED_KEY, JSON.stringify(fresh));
    return fresh;
  } catch (err) {
    console.warn("data-api verified read failed", err);
    return stale;
  }
}

export async function verifiedIds(env: Env, deps: EdgeCacheDeps): Promise<Set<string>> {
  const v = await loadVerified(env, deps).catch(() => null);
  return new Set(v?.verified.map((x) => x.id) ?? []);
}

export function handleVerified(req: Request, env: Env, deps: EdgeCacheDeps = {}, read?: Read): Promise<Response> {
  return cached(req, deps, "verified", async () => {
    const v = await loadVerified(env, deps, read);
    return v ? v1Json(req, v, VERIFIED_TTL_S) : v1Error(503, "Verified projects are not available right now. Retry later.");
  }, VERIFIED_TTL_S);
}
```

```ts
/**
 * One-off: load Data API v1 history into registrai-data from the index server's hourly archives.
 *   scp -r root@<radar>:/opt/abi/out/archive  <archive-dir>      (read-only copy)
 *   scp root@<radar>:/opt/abi/out/index*.json <current-dir>
 *   npx tsx scripts/data-api-backfill.ts <archive-dir> <current-dir> /tmp/backfill.sql
 *   (cd builders-site && npx wrangler d1 execute registrai-data --remote --file /tmp/backfill.sql)
 * Idempotent (INSERT OR REPLACE), so a re-run or an overlap with live pushes is harmless.
 */
import { readFileSync, readdirSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { gunzipSync } from "node:zlib";
import type { AbiData } from "../src/lib/builders-index";
import { indexHourRows, memberHourRows, type IndexId } from "../builders-site/lib/data-api-rows";
import { upsertSql } from "../builders-site/lib/data-api-ingest";

const lit = (v: unknown) => (typeof v === "string" ? `'${v.replace(/'/g, "''")}'` : String(v));

export function backfillStatements(files: { index: IndexId; data: AbiData }[]): string[] {
  const rows = files.flatMap(({ index, data }) => [...indexHourRows(index, data), ...memberHourRows(index, data)]);
  return upsertSql(rows).map(({ sql, params }) => { let i = 0; return sql.replace(/\?/g, () => lit(params[i++])) + ";"; });
}

const SUFFIX: Record<string, IndexId> = { "index.json": "abi", "index-aii.json": "aii", "index-aei.json": "aei" };

function main([archive, current, out]: string[]) {
  const files: { index: IndexId; data: AbiData }[] = [];
  for (const day of readdirSync(archive).filter((d) => /^\d{8}$/.test(d)).sort())
    for (const f of readdirSync(join(archive, day)).sort()) {
      const m = f.match(/^\d{8}T\d{2}-(index(?:-aii|-aei)?\.json)\.gz$/);
      if (!m) continue;
      try { files.push({ index: SUFFIX[m[1]], data: JSON.parse(gunzipSync(readFileSync(join(archive, day, f))).toString()) }); }
      catch (e) { console.warn("skipped unreadable archive", f, String(e)); }
    }
  for (const [name, index] of Object.entries(SUFFIX)) files.push({ index, data: JSON.parse(readFileSync(join(current, name), "utf8")) });
  const sql = backfillStatements(files);
  writeFileSync(out, sql.join("\n") + "\n");
  console.log(`wrote ${sql.length} statements from ${files.length} files to ${out}`);
}

if (process.argv[1]?.endsWith("data-api-backfill.ts")) main(process.argv.slice(2));
```
