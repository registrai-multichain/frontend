**Subject:** Listing request: Registrai, hourly Arc app data (API + MCP)

ecosystem directory and on the docs "Data indexers" page.

What it is:

  Page: https://builder.registrai.cc/apps/
- **A public JSON API:** no key, CC BY 4.0, with an OpenAPI 3.1 description.
  https://builder.registrai.cc/data-api/
- **A read-only MCP server** for AI agents, listed in the official MCP Registry as `cc.registrai/arc-data`:
  https://builder.registrai.cc/api/mcp
- **Verified builders:** projects with a signed proof in our builder registry on Arc mainnet.
