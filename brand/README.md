# Registrai brand kit

Registrai is **the anti-launchpad**: `$REGI` bootstraps the Registrai network on Arc, while Perennial redirects prediction-market value into verified builder work instead of making every builder launch a token. The identity is editorial and infrastructural; the mark should never collapse into generic memecoin art.

## The Cut-R

The mark is a heavy `R` interrupted by an orange redistribution seam. The dark body signals durable market infrastructure; the orange wedge is value changing direction. It works as a favicon before it works as an illustration.

## Colour

- **Night** `#0D0D0C` — primary field and dark ink
- **Paper** `#F1EDDC` — primary light field
- **Redirect orange** `#FF5A1F` — the redistribution seam; never decorative fill
- **Verified acid** `#C9FF3D` — live and verified status only

## Typography

- **Instrument Sans 700** — wordmark and display identity
- **Instrument Serif Italic** — editorial emphasis
- **JetBrains Mono** — market data, labels, and protocol detail

The wordmark is title case: `Registrai`. Do not set the primary wordmark in spaced all caps.

## Clear space and minimum size

Keep clear space equal to the width of the orange wedge on all sides. Minimum digital size is `18px` for the standalone mark and `92px` for the lockup. Below `18px`, use the monochrome mark.

## Do not

- Enclose the mark in a coin or ring.
- Add gradients, shadows, outlines, or 3D effects.
- Recolour the wedge as a generic accent.
- Stretch, rotate, or rearrange the mark.
- Pair it with rockets, candlesticks, chain links, or token imagery.
